# Веса моделей

Чекпоинты из `solution-final.ipynb` сохраняются сюда (имена совпадают с кодом в ноутбуке):

| Файл | Описание |
|------|----------|
| `model_fold{0..4}.pth` | Stage 1: лучшие веса по validation AUC для каждого фолда. |
| `model_fold{0..4}_distill.pth` | Stage 2: дистилляция поверх Stage 1. |

**Инференс:** если есть `model_fold0_distill.pth`, подхватываются дистиллированные веса и веса ансамбля считаются по `distill_scores`, иначе — Stage 1 и `fold_scores`.

## Старые веса другого эксперимента

В `legacy_weights_seresnet/` лежат файлы `model_fold_seres*.pth` — это **другой нейминг** (не используется текущим `solution-final.ipynb` без правок кода). Их можно удалить или оставить как архив.
