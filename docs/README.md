## 1. Соревнование в целом

**Название:** [Plant Pathology 2020 — FGVC7](https://www.kaggle.com/c/plant-pathology-2020-fgvc7) (Fine-Grained Visual Categorization workshop / Kaggle).

**Задача:** по фотографии листа яблони предсказать один из **четырёх классов**:

- `healthy` — здоровый лист  
- `multiple_diseases` — комбинация болезней  
- `rust` — ржавчина  
- `scab` — парша  


**Формат меток в train:** one-hot по четырём столбцам (ровно один класс активен на изображение).

**Метрика соревнования:** **macro-averaged ROC-AUC** — для каждого класса считается одномерная ROC-AUC «один класс против остальных» (one-vs-rest), затем усреднение по классам. Классы несбалансированы (особенно `multiple_diseases`), поэтому macro-AUC честнее, чем accuracy.

**Типичные сложности датасета:**

- Высокое разрешение, разный масштаб листа в кадре.  
- **Шум в разметке и дубликаты:** одно и то же (или очень похожее) изображение может встречаться с разными метками — в вашем пайплайне это учитывается через **StratifiedGroupKFold** и **дистилляцию по OOF**.

## 2. Анализ чужих решений: модели, хаки, что реально работает

Ниже — обобщение типичных сильных public-решений на Kaggle для этой задачи и похожих задач по классификации болезней растений.

### 2.1. Какие модели чаще всего используют

- EfficientNet (B3-B7)
- SE-ResNeXt / ResNeXt
- Ансамбли нескольких backbone

Почему: дают хороший баланс качества и переносимости с ImageNet-предобучения.

**Валидация и утечки:** **StratifiedGroupKFold** по полю `dup_group`, чтобы дубликаты не попадали одновременно в train и valid.

**Инференс:** для каждого фолда — **4 детерминированных TTA** (оригинал + горизонтальное и вертикальное отражение + оба), усреднение вероятностей; затем **взвешенный ансамбль** 5 моделей, веса пропорциональны **AUC фолда** (Stage 2, если есть дистиллированные веса, иначе Stage 1).

**Работа с шумными метками**:
   - label smoothing,
   - distillation на soft targets,
   - mixup/cutmix,
   - иногда focal loss.

## 3. Stage 1, Stage 2, мягкие метки, TTA и ссылки на код


### 3.1. Базовый выбор модели

**Модель:** [`seresnext50_32x4d`](https://github.com/huggingface/pytorch-image-models/blob/main/timm/models/seresnext.py) в [timm](https://github.com/huggingface/pytorch-image-models) (SE-ResNeXt-50, группы 32×4d). **Статьи:** SE-модуль — [Squeeze-and-Excitation Networks (Hu et al., CVPR 2018)](https://arxiv.org/abs/1709.01507); стек ResNeXt — [Aggregated Residual Transformations for Deep Neural Networks (Xie et al., CVPR 2017)](https://arxiv.org/abs/1611.05431).
ResNeXt: как ResNet, но внутри блока свёрток используется grouped convolution с параметром cardinality (здесь 32 группы) и шириной ветки 4. Идея: больше “параллельных преобразований” → лучшее качество при близком бюджете.
SE (Squeeze‑and‑Excitation): добавляет внимание по каналам: сеть сама “подкручивает” важность каналов признаков (через global pooling + маленькую MLP + sigmoid).
Почему подходит тут: для fine‑grained текстур/пятен на листьях такие CNN‑бэкбоны обычно сильные и хорошо дообучаются с ImageNet.

### 3.2. Stage 1 (жёсткие метки)

- Обучение на 5 фолдах с `CrossEntropyLoss`.
- На каждом фолде сохраняется лучший чекпоинт по validation AUC.
- Формируются OOF-предсказания на всём train.

**Зачем:** получить сильную базу и честные OOF-вероятности для следующего этапа.

### 3.3. Stage 2 (distillation на мягких метках)

- Мягкая цель: `soft = 0.3 * OOF + 0.7 * one-hot`.
- Для обучения используется KL-логика (через `log_softmax + kl_div`).
- Старт весов берётся из Stage 1, потом дообучение с меньшим LR и `CosineAnnealingLR`.

**Зачем:** снизить эффект шумных/спорных меток, сделать модель менее «жёсткой» и более устойчивой.

### 3.4. Инференс

- TTA из 4 детерминированных вариантов (оригинал + 3 отражения).
- Усреднение вероятностей внутри фолда.
- Взвешенный ансамбль фолдов по их AUC.

**Зачем:** уменьшить дисперсию предсказаний и поднять стабильность на тесте.

### 3.4. TTA и ансамбль на test

- **Ячейка 24 (code):**

- **Пояснение `mixup_data(...)`:** функция берёт пары объектов в батче и строит смешанный пример: `x_mix = λ * x_i + (1 - λ) * x_j`, а целевую метку смешивает так же: `y_mix = λ * y_i + (1 - λ) * y_j`. Это уменьшает переобучение и снижает переуверенность модели на шумных/пограничных примерах.

## 6. Теория: модели и приёмы из ноутбука

### 6.1. Сверточная сеть (CNN)

Свёртка — **локальный линейный фильтр с разделением по каналам** + нелинейность. Иерархия слоёв даёт **от низкоуровневых** (края, текстура) **к высокоуровневым** (части объекта, контекст).

### 6.2. Residual learning (ResNet)

Остаточные блоки `y = F(x) + x` облегчают оптимизацию глубоких сетей: слоям проще учить **поправку** к тождественному отображению. Статья: [Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385).

### 6.3. SE (Squeeze-and-Excitation)

**Squeeze:** глобальный пулинг по пространству → вектор по каналам.  
**Excitation:** небольшая MLP + sigmoid → **веса каналов** 0…1, умножение на карты признаков.  
Интерпретация: **внимание по каналам**. Статья: [Squeeze-and-Excitation Networks](https://arxiv.org/abs/1709.01507).

### 6.4. ResNeXt и cardinality

Несколько параллельных «веток» с одинаковой топологией и последующее объединение — рост **разнообразия** фильтров без такого же роста параметров, как у очень широкой одной ветки. Статья: [Aggregated Residual Transformations for Deep Neural Networks](https://arxiv.org/abs/1611.05431).

### 6.5. Knowledge Distillation (в широком смысле)

Классическая дистилляция: большая «teacher» → маленькая «student». В вашем случае **teacher — ансамбль самой же архитектуры в OOF**, student — та же сеть на мягких метках. Идея та же: перенос **распределения** знаний, а не только argmax. Оригинальная идея: [Distilling the Knowledge in a Neural Network](https://arxiv.org/abs/1503.02531) (Hinton et al., 2015).

### 6.6. Macro ROC-AUC (multiclass)

Для каждого класса строится бинарная задача: этот класс vs остальные; считается AUC по порогам вероятности; затем **среднее по классам**. Чувствительна к качеству на **редких** классах сильнее, чем micro-AUC.

### 6.7. StratifiedGroupKFold

- **Stratified** — сохраняем пропорции классов в каждом фолде.  
- **Group** — объекты одной группы целиком в train **или** целиком в valid.  
Документация: [sklearn.model_selection.StratifiedGroupKFold](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.StratifiedGroupKFold.html).

### 6.8. Perceptual hash (dHash)

Быстрый дескриптор изображения для **поиска почти дубликатов**. Не даёт гарантии «одинаковые пиксели», но хороший эвристический фильтр для EDA.

### 6.9. AdamW и OneCycleLR

- **AdamW:** Adam с **развязанным** weight decay (штраф за величину весов 
ведётся корректнее). Статья: [Decoupled Weight Decay Regularization](https://
arxiv.org/abs/1711.05101).  
- **OneCycleLR:** краткий разгон LR, затем спад — часто ускоряет сходимость. 
Статья/отчёт: [A disciplined approach to neural network hyper-parameters]
(https://arxiv.org/abs/1803.09820).


1. В задаче важна не accuracy, а **macro ROC-AUC**, потому что классы несбалансированы.
2. Из-за дубликатов обычный split опасен; поэтому использован **StratifiedGroupKFold**.
3. Stage 1 строит базовые fold-модели и OOF, Stage 2 использует OOF как мягкий «учитель».
4. TTA + ансамбль фолдов снижают variance и повышают устойчивость результата.
5. Выбранная архитектура — это осознанный компромисс качества и ресурсов, а не случайный выбор.
