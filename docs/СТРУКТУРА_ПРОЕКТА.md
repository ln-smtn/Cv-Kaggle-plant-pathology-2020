# Структура репозитория (после приведения в порядок)

В корне остаётся **основной ноутбук** и служебные каталоги.

```
CV_Kaggle/
├── solution-final.ipynb    # единственный рабочий пайплайн
├── data/
│   └── plant-pathology-2020-fgvc7/   # train.csv, test.csv, images/
├── models/                 # *.pth (в .gitignore), см. models/README.md
├── logs/
│   ├── README.md
│   ├── history/            # training_log.csv
│   └── reports/            # текстовые сводки
├── outputs/                # submission.csv после ячейки Submission
├── docs/                   # материалы для защиты, requirements
└── archive/                # старые ноутбуки, сабмиты, скрипты (не нужны для запуска)
```

**Kaggle:** в ноутбуке `CFG.data_dir` переключается на `/kaggle/input/competitions/...`, если локальной папки `data/...` нет.
